# University Landing Page

A modern and responsive **university landing page** built with **React**, showcasing programs, campus facilities, student testimonials, and contact information. This project uses modular React components to ensure maintainability and scalability.

---

## Features

- **Responsive Navbar:** Easy navigation across sections  
- **Hero Section:** Highlighting the university’s key message  
- **Programs Section:** Showcasing offered courses and programs  
- **About Section:** Overview of the university  
- **Campus Gallery:** Photos of campus facilities  
- **Testimonials:** Feedback from students  
- **Contact Form:** For inquiries and communication  
- **Footer:** Contains links, social media, and other relevant info  
- Modular React components for easy reuse and customization  

---

## Technologies Used

- **React** – Frontend library for building UI  
- **JavaScript (ES6+)** – Logic and interactivity  
- **CSS / SCSS** – Styling and layout  
- Optional libraries (can be added as needed):  
  - React Icons  
  - Swiper.js / React Carousel  
  - Axios (for form submissions)
